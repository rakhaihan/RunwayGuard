# RunwayGuard AI

Intelligent Runway Foreign Object Debris (FOD) Detection System — early prototype for Boeing BUILD Indonesia.

## Structure

- `frontend/` — React + Vite + Tailwind dashboard
- `backend/` — FastAPI + OpenCV detection service (YOLO-ready via `DetectorPort`)
- `docs/` — Architecture, API, folder index, demo script

See [docs/FOLDER_STRUCTURE.md](docs/FOLDER_STRUCTURE.md) for every file's responsibility.
